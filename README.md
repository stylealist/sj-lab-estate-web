# sj-lab 부동산 실거래

국토교통부가 공개하는 **아파트 매매·전월세 실거래** 데이터를 보는 화면입니다.
sj-lab 플랫폼의 네 번째 서비스로, 허브 첫 화면의 "부동산 실거래" 카드로 들어옵니다.

## 무엇을 볼 수 있나

- **매매** — 월별 거래량과 평균·중위 가격 추세, 최근 거래 목록(단지·면적·층·금액·㎡당)
- **전월세** — 전세 보증금 추세, 월별 전세/월세 구성과 평균
- **단지** — 지역 안의 단지를 거래 많은 순으로 찾고, 단지를 누르면 **평형별 시세·추세·최근 거래**를 봅니다
- **지역 순위** — 선택한 기간의 시군구별 평균 매매가. 지역명을 누르면 그 지역 매매로 이동

조건은 **지역(시도 → 시군구 → 읍면동) · 기간 · 단지명**으로 좁힙니다. 단지명은 일부만 입력해도 찾습니다.
지역을 좁히면 조회가 빨라집니다(동 단위는 수십 ms).

첫 화면은 **서울 강남구 · 최근 12개월**로 시작합니다 — 전국을 기본값으로 두면 평균·중위 계산 때문에
화면이 몇 초 멈춥니다. 전국도 고를 수 있고, 선택지에 그 사실을 적어 두었습니다.
조회 중에는 화면 맨 위에 얇은 로딩바가 보입니다.

헤더에서 **소개**(데이터가 어디서 와서 어떻게 보이는지, 지금 없는 것)와
**저장소 · 문의**(공개 저장소 · 이메일 · 플랫폼 주소)로 넘어갈 수 있습니다 — 지도 사이트와 같은 구성입니다.

## 데이터

| | 내용 |
|---|---|
| 매매 | 9,911,036건 · 2006-01 ~ 2026-10 (250개월) |
| 전월세 | 11,494,802건 · 2011-01 ~ 2026-10 |
| 지역 | 220개 시군구 |
| 출처 | 국토교통부 실거래가 공개시스템(공공데이터포털) |
| 갱신 | 매일 06시(매매) · 07시(전월세) 자동 수집 |

금액은 원천 그대로 **만원 단위**로 들어오고, 화면에서 "8억 5,000만" 형태로 바꿔 보여 줍니다.
전세·월세는 **월세가 0인지**로 가릅니다.

## 어떻게 동작하나

```
브라우저 → 게이트웨이(api.sj-lab.co.kr) → sj-lab-estate → PostgreSQL(estate 스키마)
                                            ▲
                              sj-lab-scheduler 가 매일 수집해 적재
```

이 저장소는 **화면만** 담당합니다. 데이터 조회는 `sj-lab-estate` 의
`/estate/**` 를 호출하고, DB에 직접 붙지 않습니다.

차트는 **외부 차트 라이브러리 없이** 인라인 SVG로 직접 그립니다 — 의존성은
`react`·`react-dom` 둘뿐입니다.

## 실행

```bash
npm install
npm start        # http://localhost:4200
npm run build    # build/ 에 정적 파일
```

로컬에서는 webpack dev server가 API 호출을 게이트웨이(8100)로 넘겨 CORS 설정 없이 동작합니다.
조회 서버를 따로 띄워 확인할 때는 `ESTATE_PROXY_TARGET=http://localhost:8120 npm start`.

**로그인이 필요합니다.** 토큰이 없으면 공유 로그인 페이지로 보내고, 돌아올 때 받은 토큰을
이 사이트의 `localStorage` 에 저장합니다(허브·지도·API 센터와 같은 방식).

## 화면이 비어 있을 때

```
GET /estate/status
```

`ready: false` 면 조회 API 쪽 DB 접속 설정(`ESTATE_DB_DSN`)이 없는 상태입니다.
그 경우 이 화면만 안내 문구를 띄우고, 다른 서비스는 영향받지 않습니다.

## 현재 한계

- **운영 배포 전입니다.** 지금은 로컬에서만 동작하고, 운영에는 Jenkins 잡과 정적 경로
  (`sj-lab.co.kr/estate/`), 운영 DB의 표 생성이 남아 있습니다.
- **지도에 뿌리지 않습니다.** 원천 데이터에 좌표가 없어 주소 텍스트만 있습니다.
- 해제된 계약(`cdeal_type`)은 목록에 "해제" 표시만 하고 집계에서 빼지는 않습니다.
- 전월세는 2011년부터입니다(그 전은 공개 데이터가 없습니다).
